# BhashaBridge AI — Smart India Hackathon 2026

## Project Overview

Build an offline-first AI teaching assistant for tribal primary education in Jharkhand.

Target language prototype:
Hindi ↔ Santhali.

Future languages:
Ho, Mundari.

Target users:
Primary school teachers who do not know tribal languages.

## Technology Stack

Frontend:

* React 19
* TypeScript
* Vite
* Tailwind CSS v4
* Framer Motion
* Lucide React

Backend:

* FastAPI
* SQLite
* Python 3.12

AI Stack:

* IndicTrans2
* Whisper Tiny
* Piper TTS
* ONNX Runtime

Features:

* Real-time translation.
* Voice-to-voice translation.
* Lesson planner.
* Worksheet generator.
* Flashcard generator.
* Story generator.
* Offline content library.

## Design Principles

The UI must look like Duolingo + Google Gemini + Khan Academy Kids.

Use Material Design 3.

Use glassmorphism.

Rounded 24px corners.

Pastel educational color palette.

Responsive tablet-first layout.

Never generate government-style UI.

## Coding Rules

Never recreate the project.

Modify existing files.

Use reusable components.

Use React Router.

Use Zustand for state management.

Write production-quality code.

Use TypeScript everywhere.

Never use any paid service.
